# Module 9A - Build Your First React Component

## Description
This is a React app created using Vite that renders a UserProfile component. The component includes a name, bio, and image styled with inline CSS.

## What I Learned
- How to set up a React project using Vite
- How to write and structure a functional React component
- How to use JSX and inline styles
- How to render a component in App.jsx

## Challenges
I ran into a few issues along the way. First, when creating UserProfile.jsx in Notepad, the file saved as empty the first time, which caused an error saying the module didn't export a default. I fixed it by reopening the file and re-pasting the code, making sure to confirm the `export default` line was actually there before saving. Second, the profile image in the assignment instructions returned a 404 error, meaning the photo had been removed from Unsplash. The component code itself was correct and matched the assignment exactly, the image URL was just no longer valid on Unsplash's end.
